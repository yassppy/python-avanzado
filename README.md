# Python Avanzado

Se utiliza uv para gestionar el entorno virtual, aislando las depedencias para evitar conflictos con otros proyectos. Además, incorporamos Ruff como linter (verifica la calidad del código sin errores ni variables sin utilizar) y formatter (manetener un formato limpio).
